# EASA eRules Hub v3.6 - Publication Builder

## What is new?

The new **Yayin Olusturucu (Publication Builder)** combines excerpts from a chosen
EASA XML release into downloadable research and reading material. It does not
bundle any regulation data or change your existing Firebase / Drive records.

- Choose a publication family and a specific source XML release.
- Search/filter requirements, and select whole records or individual numbered clauses.
- Preserve the XML's record order and the parent/subclause structure.
- Optionally add directly connected AMC / GM / CS records when `ParentIR` metadata matches.
- Optionally export existing Firestore general and clause notes, clearly marked
  as personal annotations and separate from the original legislation.
- Generate DOCX, EPUB, TXT and Markdown files directly in the browser.
- Open A4 PDF and Kindle Scribe PDF layouts in a print-preview tab, then
  select **Print / Save as PDF**. Kindle offers Reading and Handwriting profiles.
- Add 0, 1, or 2 blank ruled note pages after each chosen requirement (DOCX / PDF).

## PDF and Kindle use

PDF: the app opens an A4 or Kindle print layout in a separate browser tab.
Press **Print / Save as PDF** and set the printer destination to "Save as PDF".
For the Kindle-specific PDF, keep the preconfigured page size (186 x 248 mm),
prefer no browser header/footer, and use the browser's "background graphics" option.
The sample PDF was verified at that page size.

To handwrite on PDFs with Kindle Scribe 2024, transfer through **Send to Kindle**.
EPUB is a reflowable ebook with a linked TOC for fast chapter navigation.
Word has real heading styles and linked entries in its contents page.
Internal PDF links are generated by the print engine; Kindle support for
internal PDF navigation may vary. EPUB is preferable for reliable chapter TOC.

## Important limits of this phase

- The builder works with one selected XML publication/version per compilation.
  Mixing multiple publication families and saving reusable report templates to
  Firestore are planned for later releases.
- Selected clauses include required parent context. Some original EASA tables
  may not be ideal on Kindle and embedded drawings/images are not reconstructed
  by the existing XML parser. Inspect exports before regulatory use.
- The report is generated locally in the browser; no new Drive file, Firebase
  collection, or sharing operation is created by the export.
- Personal notes have their own marks. Do not interpret annotations as official law.
- The generated version is a snapshot of the exact selected uploaded XML release;
  nothing is auto-synchronized from EASA. Verify legal applicability independently.
- Large compilations are capped at 350 records per export to limit browser memory usage.
